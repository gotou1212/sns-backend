SQL
SQLはバックエンドからDBにこれやってねっていう申請書みたいなもの
SQLはSELECT、INSERT、UPDATE、DELETE
取得はSELECT
作成はINSERT
更新はUPDATE
削除はDELETE
別々のテーブルにあるデータをくっつけて一緒に取得するのはJOIN
データの被りを起こさないのはUNIQUE
入れるデータの条件・ルールを指定するフィルターはCHECK
データを早く探すことができるのはINDEX

countについて
count(*)
全ての行を数える
count(列名)
指定した列のデータだけを数える
count(DISTINCT)
重複している値を除外して数える
GROUP BY
カテゴリやグループごとにそれぞれ何件あるかを集計する。
